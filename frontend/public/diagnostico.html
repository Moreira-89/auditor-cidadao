Diagnóstico de conectividade

Descobre em que camada o upload está sendo barrado. Página temporária.

1. GET / (controle)

Confirma que o backend responde a partir deste dispositivo.

—

2. POST com JSON

POST sem arquivo, com preflight. Qualquer status HTTP significa que passou da borda.

—

3. POST multipart pequeno (~1 KB)

Mesmo formato do upload real, corpo mínimo.

—

4. POST multipart grande (~6 MB)

Isola bloqueio por tamanho do corpo.
